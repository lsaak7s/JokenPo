# 👊✋✌️ JokenPô

Um jogo de **Pedra, Papel e Tesoura** desenvolvido com **HTML, CSS e JavaScript**, onde você joga contra o computador.

## 🚀 Funcionalidades

- 🎮 Jogue contra o computador.
- 🤖 Escolhas aleatórias do computador.
- 🏆 Sistema que identifica o vencedor.
- 📊 Contador de pontos do jogador.
- 💻 Contador de pontos do computador.
- 🌄 Fundo que muda automaticamente a cada atualização da página.
- 📱 Interface simples e responsiva.

---

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript

---

## ▶️ Como executar

1. Clone o repositório:

```bash
git clone https://github.com/lsaak7s/JokenPo.git
```

2. Abra o arquivo `index.html` no navegador.
